# EmberNexus

EmberNexus is a real-time, microservices-oriented platform that enables scalable event-driven applications via a flexible gateway.

With EmberNexus, you get a lightweight tool that stays out of your way.

**What you get**

- EmberNexus is a real-time, microservices-oriented
- platform that enables scalable event-driven
- applications via a flexible gateway

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/EmberNexus.git`
2. `cd EmberNexus`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
